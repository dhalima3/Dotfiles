# My dotfiles

## New Mac setup

1. Sign in to the Mac App Store.
2. Run `scripts/brew.sh` to install Homebrew packages, applications, and Mac App Store applications from `Brewfile`.
3. Run `scripts/zsh.sh`.
4. Run `./install` to link dotfiles
5. Run `scripts/.macos` to apply macOS, iTerm2, Chrome, and Brave preferences.
6. Follow `checklist.md` for the remaining account, license, and app-specific steps.
